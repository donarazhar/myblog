MyBlog Deployment Guide

1

Install Dependencies

Install semua package yang dibutuhkan untuk menjalankan Laravel.

Update System & Install PHP 
# Update system
apt update && apt upgrade -y

# Install PHP 8.2+ dan extensions
apt install -y php php-cli php-fpm php-mysql php-mbstring php-xml php-curl php-zip php-gd unzip git nginx mysql-server
Install Composer & Node.js 
# Install Composer
curl -sS https://getcomposer.org/installer | php
mv composer.phar /usr/local/bin/composer

# Install Node.js 20
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
2

Clone Repository

Clone project dari GitHub ke folder /var/www.

Clone dari GitHub 
cd /var/www
git clone https://github.com/donarazhar/myblog.git
cd myblog
3

Setup Laravel

Install dependencies dan konfigurasi environment.

Install & Configure 
# Install dependencies
composer install --no-dev --optimize-autoloader

# Copy dan edit .env
cp .env.example .env
nano .env
⚠️
Penting! Edit file .env sesuai konfigurasi server Anda.
Variable Value
APP_ENV production
APP_DEBUG false
APP_URL http://192.168.13.77
DB_DATABASE myblog
DB_USERNAME root
DB_PASSWORD your_password
4

Setup Database

Buat database MySQL dan jalankan migrasi.

Create Database 
# Masuk ke MySQL
mysql -u root -p

# Buat database
CREATE DATABASE myblog;
exit;
Run Migrations 
# Generate key & migrate
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
5

Build Frontend

Install npm packages dan build assets untuk production.

Build Assets 
npm install
npm run build
6

Set Permissions

Set ownership dan permissions yang benar untuk Laravel.

Set Ownership & Permissions 
chown -R www-data:www-data /var/www/myblog
chmod -R 755 /var/www/myblog/storage
chmod -R 755 /var/www/myblog/bootstrap/cache
7

Konfigurasi Nginx

Buat virtual host Nginx untuk Laravel.

Buat file konfigurasi 
nano /etc/nginx/sites-available/myblog
Nginx Configuration 
server {
    listen 80;
    server_name 192.168.13.77;
    root /var/www/myblog/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;
    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
8

Enable & Restart

Aktifkan site dan restart Nginx.

Enable Site & Restart 
# Enable site
ln -s /etc/nginx/sites-available/myblog /etc/nginx/sites-enabled/

# Hapus default site
rm /etc/nginx/sites-enabled/default

# Test & restart
nginx -t
systemctl restart nginx
✅
Local Access Ready! Website dapat diakses via http://192.168.13.77 dalam jaringan lokal.

Cloudflare Tunnel Setup

Expose server lokal ke internet dengan domain donarazhar.site menggunakan Cloudflare Tunnel.

9

Install Cloudflared

Download dan install Cloudflared daemon.

Download & Install 
# Download cloudflared
curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb

# Install
dpkg -i cloudflared.deb

# Verify installation
cloudflared --version
10

Create Tunnel

Login ke Cloudflare dan buat tunnel baru.

Login & Create Tunnel 
# Login ke Cloudflare (akan membuka URL di browser)
cloudflared tunnel login

# Buat tunnel baru
cloudflared tunnel create myblog
📝
Catat Tunnel ID! Setelah membuat tunnel, akan muncul Tunnel ID yang dibutuhkan untuk konfigurasi. Format: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
11

Configure Tunnel

Buat file konfigurasi dan route DNS.

Create Config File 
nano ~/.cloudflared/config.yml
Config YAML 
tunnel: <TUNNEL_ID>
credentials-file: /root/.cloudflared/<TUNNEL_ID>.json

ingress:
  - hostname: donarazhar.site
    service: http://localhost:80
  - hostname: www.donarazhar.site
    service: http://localhost:80
  - service: http_status:404
Route DNS 
# Route domain ke tunnel
cloudflared tunnel route dns myblog donarazhar.site
cloudflared tunnel route dns myblog www.donarazhar.site
Update Laravel .env 
# Update APP_URL di .env
nano /var/www/myblog/.env

# Ubah menjadi:
APP_URL=https://donarazhar.site

# Clear cache
cd /var/www/myblog && php artisan config:cache
12

Run as Service

Jalankan tunnel sebagai system service agar auto-start saat boot.

Test & Install Service 
# Test tunnel (Ctrl+C untuk stop)
cloudflared tunnel run myblog

# Jika berhasil, install sebagai service
cloudflared service install
systemctl start cloudflared
systemctl enable cloudflared

# Cek status
systemctl status cloudflared
